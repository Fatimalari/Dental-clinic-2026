# Lumen Dental — clinic website

A static, five-page dental clinic website: **Home**, **About**, **Services**, **Blog** and **Contact**.
Plain HTML, CSS and JavaScript, with no build step. Open `index.html` in a browser, or host the folder anywhere (GitHub Pages, Netlify, etc.).

## Design
- **Colours:** deep green `#3e5c55`, lavender `#dde0ff`, cream `#f8f6f1`, mint `#e6f1ea` (set as variables at the top of `styles.css`)
- **Fonts:** Montserrat for headings, Open Sans for body text (Google Fonts)

## Before going live
- Replace the placeholder clinic name, address, phone, email, team, prices and reviews.
- Swap the illustrations in `assets/` for real photos (keep the same file names, or update the `src` paths).
- Connect the booking and newsletter forms to a form service (e.g. Formspree or Netlify Forms). Right now they only validate in the browser.
- Replace the map placeholder on `contact.html` with a Google Maps embed.
- Blog cards link to `#`. Add an article page per post.
