# Smileyce — dental clinic website

Static landing page (HTML, CSS, vanilla JS). No build step: open `index.html` or host the folder anywhere.

- Font: Manrope (Google Fonts)
- Images: see `assets/images/README.md` for file names
- Motion: hero entrance, image reveal, scroll-lit mission text, parallax photos, count-up stats, staggered card reveals. All of it is disabled when the visitor's system has "reduce motion" turned on.
